# 모일때 — When2meet UI Renewal

When2meet의 핵심 흐름을 단순하게 유지하면서 한국어 사용성을 개선한 정적 웹 앱입니다.

## 포함 기능

- 이벤트 이름 정의
- 클릭·드래그로 복수 후보 날짜 선택/해제
- 클릭·드래그 방식의 30분 단위 가능 시간표
- `Asia/Seoul` 타임존 고정
- 참가자별 가능 시간 저장과 수정
- 가장 많이 겹치는 시간 자동 표시
- 이벤트·참가자 응답을 포함한 공유 링크
- 데스크톱/모바일 반응형 UI
- 별도 빌드나 외부 라이브러리 없이 실행

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다.

로컬 서버로 확인하려면 이 폴더에서 아래 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages에 올리기

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상단에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
4. `main` 브랜치와 `/ (root)` 폴더를 선택하고 저장합니다.

## 공유 방식

이 버전은 서버 없는 정적 사이트입니다. 이벤트 정보와 참가자 응답은 URL의 `#event=...` 부분에 담깁니다. 참가자가 응답을 저장한 뒤 **공유 링크 복사**를 눌러 최신 링크를 다시 전달하면 누적된 시간표를 함께 볼 수 있습니다.

모든 사용자의 응답을 별도 링크 전달 없이 실시간으로 합치려면 Firebase, Supabase 같은 데이터 저장소를 추가해야 합니다.
